# CircleUp — Architecture & Technical Walkthrough

**Project:** CircleUp — Social Activity Discovery & Organization Platform  
**Stack:** Python / FastAPI · PostgreSQL · Vanilla HTML / CSS / JS  
**Version:** 1.0.0

---

## 1. Product Overview

CircleUp is a web platform where users create social activity invitations,
discover activities created by others, request to join them, and connect
with participants once approved.

**Core design principle:** Single user type — no admin or moderator roles.
Permissions on an activity belong exclusively to its creator.

## 3. Technology Stack

| Layer            | Technology        | Reason                                                 |
| ---------------- | ----------------- | ------------------------------------------------------ |
| Backend Language | Python 3.12       | Clear, productive, strong ecosystem                    |
| Web Framework    | FastAPI           | Auto-generates Swagger docs, Pydantic built-in         |
| Database         | PostgreSQL 16     | ACID compliance, `SELECT FOR UPDATE` for concurrency   |
| ORM              | SQLAlchemy 2.0    | Mature, supports all needed query patterns             |
| Auth             | JWT (PyJWT)       | Stateless + server-side revocation via token blacklist |
| Password Hashing | bcrypt            | Industry-standard, salted, resistant to brute-force    |
| Validation       | Pydantic v2       | Schema-level validation with field validators          |
| Frontend         | HTML + CSS + JS   | No frameworks — as required by SRS                     |
| API Docs         | Swagger / OpenAPI | Auto-generated by FastAPI at `/docs`                   |
| Testing          | pytest + httpx    | Clean, isolated unit tests with SQLite in-memory       |
